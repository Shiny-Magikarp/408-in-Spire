日期：2026-10-27。正式权重更新为`wakuu-nli-408-dev3`，从dev2继续微调。运行时仍使用0.8.1的分句检索流程；语义支持概率至少0.85、矛盾概率低于0.1的给分门槛没有放宽。

## 同一组新表述上的前后对比

在候选推理前固定100条项目编写样例：四科各25条，共48条正确表述、24条错误结论、24条相关但不足以证明评分点的表述、4条要求模型直接发奖的指令文本。题目知识可能在先前领域训练中出现；新答案与参考结论的完整文本对未进入本轮训练或开发集。

| 指标 | 0.8.1 dev2 | 0.8.2 dev3 |
| --- | ---: | ---: |
| 给分决定正确 | 80/100（80%） | 92/100（92%） |
| 正确表述获得该评分点 | 33/48（68.75%） | 44/48（91.67%） |
| 错误或不完整表述被给分 | 5/52（9.62%） | 4/52（7.69%） |
| 正确表述漏分 | 15/48 | 4/48 |

这里的“正确”指是否应给某个评分点，三分类中的“矛盾”和“信息不足”都不应给分。它不是整道大题分数与人工阅卷的一致率。FP32与FP16在全部100条上的给分决定一致，因此继续部署约205MB的FP16模型。

**这是项目自编的小规模表述测试，没有独立人工标注的真实学生答卷。** 数据量、出题者偏好和领域重合都会影响结果，不能把92%外推为全部204道大题的真实批改准确率。仍有4条错误给分和4条正确答案漏分；代码、证明、绘图过程未得到通用验证，相关题目继续显示过程复核，不发额外遗物或卡牌。

样例源码：[holdout_082.py](../tools/ai/holdout_082.py)。公开汇总、配置及逐例结果：[wakuu-082.json](evaluations/wakuu-082.json)。完整留出文件SHA-256：`dc5864e6b4f99ebc6f3b9a12abed2e24fcea50410f1876631d580e0939b7baf6`。

## 这次实际训练了什么

- 从已有dev2 PyTorch检查点继续训练最后4个Transformer层、pooler和分类头，前面的层冻结。
- 共7,128条训练对，包含旧数据重放、历史诊断样例重复采样和保持含义的术语改写；这不是7,128份独立答卷。标签分布：矛盾1,235、信息不足1,572、支持4,321。
- 48条历史开发样例用于选择检查点，正确/不应给分各24条。旧0.8.1的96条测试及此前68条诊断已经转为历史训练/开发材料，不能再用作新模型的独立评测证据。
- 学习率1e-5，batch size 12，随机种子408082，训练4轮；只按开发集的“正确给分数−8×错误给分数”选择第1轮。没有用新100条样例选epoch、调阈值或增加针对性判断规则。
- 新100条在模型选择后用于比较基线、检查部署门槛与精度转换。此后只作为固定回归集；下一轮若按这些错误改模型，需要新的独立测试数据。

## 本地重现

先按README准备底模、导入题库并运行历史dev2训练，保留`.tools/ai/full-train/checkpoint`。然后：

```powershell
./TrainWakuu082.ps1
dotnet run --project tests/CoreTests.csproj
./SmokeTest.ps1
./Build.ps1 -SkipAssets -Install
```

该脚本分离训练、开发选择、固定测试与正式替换；保留dev2备份，候选未通过检查不会替换正式权重。不同硬件与库版本可能产生不同权重字节，须重新跑评估，不能直接沿用这里的结果。游戏中的复习进度会使用新模型版本标识。

后续最有价值的数据是按评分点独立标注的真实同义答案、部分正确答案和混合正误答案；收集时应获得玩家同意。本次没有读取玩家存档或上传答案。
