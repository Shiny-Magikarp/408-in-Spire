# 408 in Spire 0.8.1 试玩

目标游戏为《杀戮尖塔 2》v0.111.0。需要 RitsuLib 0.6.9。

将 Spire408 和完整 STS2-RitsuLib 文件夹放在游戏 mods 目录，重启游戏并启用。
不要漏掉 Spire408/Models/wakuu 和同级 ONNX Runtime DLL。
角色选择页点击开始后显示本局复习计划，可选择四科、章节、错题、来源筛选和大题开关。
仅单人标准模式会出现此入口；关闭复习开关可开始普通游戏。已有普通跑局不会自动转换。

复习新局持有“408计算机专业课”遗物。主描述说明激活、翻倍、战斗金币上限及大题奖励分档；下方备注保留：“一本平平无奇的专业课教材，不知道为什么透露着地狱的气息”。
界面沿用原版按钮、勾选框、下拉框、字体和纸张边框。返回固定在面板左下角，开始游戏固定在右下角；大题题库使用原版设置菜单的绿色按钮。

当前可玩选择题1,676道；未核验的OCR增补、缺图或条件歧义题已隔离。已登记版本的旧局自动跳过隔离题，已确认勘误更新错题本和统计，不追补历史金币。详见 `ACADEMIC-AUDIT.md` 与 `QUESTION-QUALITY.md`。

## 战斗选择题

默认正常出牌，不弹出选择题。需要答题增益时，先点击战斗左侧的学识徽记，看到脉动光晕后再打出目标卡牌。徽记上方没有状态文字，规则和当前状态可悬停查看。
再次点击可取消激活。触发答题后徽记自动回到静息；每次使用都需要重新点击，同一回合可以多次主动激活。
激活绑定点击后新加入队列的一张主动出牌，之前已排队的牌不会抢走激活；自动出牌也不使用或清除激活。
结束回合会取消尚未使用的激活，新战斗默认静息。旧存档中的“每张牌答题”设置已不再影响触发方式。
键盘 A/B/C/D 选择，Enter 提交。提交后显示解析，再按 Enter 或继续按钮出牌。
跳过记入错题；正确作答从错题本移除。本局仅错题模式使用开局时的错题集合。

学习模式初始金币为0；卡牌和遗物自身效果正常产金，不计入答题金币上限、不消耗答题增益次数。普通战利品金币关闭，金币事件继续使用大题挑战；花钱和失去金币保留。
首次答对每题 +10 金币，普通/精英/Boss 战上限 30/60/90，胜利时统一结算。
正确作答同时使本次主动出牌的伤害和格挡 ×2，包含多段攻击；牌的基础数值不会永久改变。
普通/精英/Boss 战分别有 3/6/9 次成功增益机会；答错或跳过不消耗机会，也不削弱卡牌。
学识徽记中央显示剩余次数，下方显示本场答题金币 x/n。静息时轻微呼吸，激活后有较明显的脉动与光晕；悬停轻微放大，点击有按压回弹。鼠标悬停可查看规则。
金币达到上限后本场停止出题，徽记变暗并禁用，后续卡牌按正常效果结算；自动出牌不出题、不消耗次数，也不获得该加成。
选择的题目用完后仍可继续出牌，徽记会禁用，悬停提示题目已做完。旧版本尚未结算的战斗按已答对题数换算至每题 10 金币并应用新上限，已结算战斗不补发、不重复计奖。

## 事件大题

已适配 11 种原版事件的金币选项，例如淹水金库、迷失鬼火、This or That。
金币选项显示“大题挑战”，先说明奖励与原选项代价。
当前大题共 204 道：126 道真题或改编题、70 道模拟题、8 道原创练习。
全部204道都有核分入口，其中124道为新增实验性语义评分，界面单独标识。代码、证明、绘图等过程未被执行或形式化验证；此类结果保留复核标记，不发额外遗物/卡牌。具体训练实测与限制见WAKUU-FULL.md。
新导入题的计算练习分合计 100，与原卷分值分开显示；过程与论述若未适配，必须对照完整答案自查。
书目、章节、错题与来源筛选同时作用于大题。

数值小问填写一个最终值，可带题目规定的单位；文字小问写清结论，建议 120 字内。
超过四个评分点时用“上一页 / 下一页”切换，答案和草稿跨页保留。
“提交评分”后展示每个评分点的得分、作答与参考答案，再点击“领取奖励”。
每题只能提交一次，暂存后重开不会重新判分。
数值题由规则核对，概念题由本地瓦库比较语义。首次加载稍慢，之后复用 CPU 会话。
模型不确定时标为“待复核”，该小问暂计 0 分，也不将整题自动标为错题；这种结果不发额外卡牌或遗物。
模型缺失、损坏、超时或答案过长时可以重试，不记为答错。

| 总分 | 金币 | 额外奖励 |
| --- | ---: | --- |
| 0–39 | 0 | 无 |
| 40–59 | 15 | 无 |
| 60–74 | 25 | 无 |
| 75–89 | 35 | 本角色稀有卡三选一 |
| 90–100 | 40 | 一件原版遗物 |

每幕的额外奖励最多一次；之后仍按分数发放金币。候选卡牌与遗物会固定，反复打开不会刷新。
领取后才执行原金币选项的生命、诅咒等代价，原选项的金币被拦截。
代价不随得分减免，0 分领取仍需支付；不想接受可以选择放弃。
“暂存返回”保留草稿；“放弃事件”和额外的“离开”选项均不收取原金币选项的代价。

大题弹窗及领奖过程中保存退出，会保留进入大题前的完整跑局快照；草稿和首次评分单独保留。
奖励和原事件执行完毕后再保存跑局，已完成事件读档后直接显示结算结果，不能重复领奖或再选另一项。

## 范围与限制

复习计划中的“大题题库”可直接搜索年份、科目、知识点、题目 ID 或题干，沿用当前科目、章节、真题和错题筛选。
点击“练习此题”后可作答、暂存和查看完整参考答案及解析；独立练习不创建跑局，也不发金币或物品。
对照算法和证明题解析后，可手动勾选“加入大题错题本”，掌握后取消。新增实验题显示参考评分点的练习分及待复核状态。
已登记版本的旧局验证原35道计奖题revision未变后迁移大题库指纹，保留旧题序，不插入新增题。未知版本停止计奖；0.7.0旧局保持80道题序，新局使用204道评分入口。跨局错题记录保留。

没有选择题、也没有启用的可计奖大题时不能开始跑局；仅有自查错题时请从“大题题库”练习。
手动标记的大题错题不会因计算结果练习得满分而自动删除，需要自己取消勾选。
“屏蔽已标注真题”无法保证未标来源的题一定不是真题。8 道大题明确标为自编练习。
概念判分模型仍是小样本开发版本，不能保证各种同义表达都判对，训练和限制详见 [WAKUU.md](WAKUU.md)。
本次 196 道候选大题已全部导入并可练习；任意算法代码、复杂证明题的可靠自动批改仍未实现。
卡牌和遗物自身产金独立于答题上限，例如古钱币、贪婪之手和Royalties。当前范围按游戏v0.111.0原版产金调用核对，第三方Mod新增产金效果未逐一适配。

开发构建：运行 Build.ps1 -Install；场景和导出绑定见 [EDITOR.md](EDITOR.md)。
