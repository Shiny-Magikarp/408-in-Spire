## 核分范围

原有8道题继续使用数值/概念混合规则。保留的69道导入题使用确定性结果核分，另118道使用1,627个实验性语义评分点。全部195道有评分入口，瓦库沿用dev3权重，本轮没有重新训练。
代码与证明过程仍未得到通用验证，64道相应题保留过程复核标记，不发额外卡牌/遗物。训练与实测边界见 [WAKUU-082.md](WAKUU-082.md)，参考答案勘误历史见 `ACADEMIC-AUDIT.md`。
未确认评分点不按满分处理；题库独立练习不发奖。实验性事件评分可按已确认练习分给金币，含复核项时不发额外奖励。

计算规则仅核对界面明确列出的结果，分数为归一到 100 的练习分，不冒充原卷各步骤的得分。
原始题目和原卷分值保留。完整答案在固定上游内容上应用带前值散列的显式勘误，不能静默改动。题库独立练习一律不产生游戏奖励，避免看到解析后重复刷金币。
评分点超过四项时按页使用已有输入框，最多支持 32 项；场景节点和导出绑定保留在编辑器中。

## 导入与追溯

双击 `ImportEssays.cmd`，或运行：

```powershell
./import_essays.ps1
./import_essays.ps1 -Offline
./Build.ps1 -SkipAssets -Install
```

导入脚本解析 TypeScript 的纯字面量，不执行上游模块，遇到函数调用、展开表达式或模板插值会拒绝。
28 个题目文件、LICENSE 与 README 共 30 个文件，SHA-256 固定于 `tools/essay-source-lock.json`；锁定时还核对了对应 Git blob。
每道题保存源路径、commit、源文件 SHA、原始 ID、年份、题号与内容修订号。
本次题干不依赖外链图片；来源已经将原图信息改写成文字、边集或参数，独立代码块也保留。

- `data/essay-upstream.json`：完整上游数据快照。
- `tools/build_essays.py`：合并、科目章节映射和明确的计算核分规则。
- `game/Spire408/Data/essays.json`：游戏使用的统一题库。
- `reports/essay-import-report.json`：来源题数与分布。
- `reports/essay-bank-report.json`：计奖与自查题数。

源码许可与题目内容的使用范围分别按上游说明保留，安装包附原 LICENSE 和 README。上游代码 MIT 许可不等于原始试题的再分发授权。
结构与来源校验不等于逐题学术校对；错误应通过原始 ID 定位修订，不静默改写上游参考答案。
