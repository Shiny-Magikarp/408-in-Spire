# 瓦库dev2：全部大题评分入口

日期：2026-10-27，Mod 0.8.0。瓦库仍在本机完全离线推理；模型FP16权重204,768,513字节，完整安装目标低于500MB。

## 覆盖与实际含义

204道题全部有评分入口：72道导入题保留确定性计算结果规则，8道自编题保留数值/概念混合规则，124道原自查题新增实验性语义核分，合计1,747个参考评分点。

新增语义评分按完整参考答案的子问和短结论生成。玩家可填写过程或伪代码，长答案分段检索，匹配最相关的短段落，逐点显示命中、冲突、缺失与待复核。语义支持概率达到0.85且矛盾概率低于0.1时给相应点分；模糊证据不自动变成满分。

这不是程序执行器、证明检查器或图像阅卷系统。70道包含代码、证明、绘图或相应过程要求的新增题始终保留过程复核标记，不发额外遗物或卡牌；可以按已确认评分点获得练习金币。其他待复核结果也不发额外奖励。练习分不代表原卷完整过程分。

## 训练

底模仍为IDEA-CCNL/Erlangshen-Roberta-110M-NLI，固定revision `864d25be3ce5e90d9193cb49d9fbd52722cdc6b0`。从原dev1本地检查点继续训练最后两个Transformer层、pooler和分类头，冻结其余层。

- 随机种子408080；AdamW学习率2e-5，weight decay 0.01；3轮，batch size 8；CUDA混合精度。
- 8,777条训练对，包含原240条自编概念对和题库参考结论的表面改写、数值/关系反例、未作答中性例。
- 1,360条开发验证、1,200条合成测试；题目ID在训练、验证、测试间不交叉。
- 按开发验证上的正确给分和错误给分选择检查点，再评估测试与另写的诊断断言。训练只产出候选，经精度和退化检查后才替换本地正式权重，旧权重备份在`.tools/ai/model-backups`。

题库派生数据在本地生成，不随公开源码仓库提交。没有把玩家作答发给远程服务，没有使用玩家存档训练。

## 测量与限制

| 检查 | dev1 | dev2 |
| --- | ---: | ---: |
| 合成开发集分类正确 | 1,245 / 1,360 | 1,342 / 1,360 |
| 合成开发集错误给分 | 53 | 10 |
| 另写68条短断言的分类正确（纯NLI） | 48 / 68 | 50 / 68 |
| 上述短断言的正确给分 | 17 / 32 | 21 / 32 |
| 上述短断言的错误给分 | 3 / 36 | 3 / 36 |

dev2合成测试分类正确1,189/1,200，正确给分678/682，错误给分9/518。合成测试与训练使用相同的构造模板；尽管按题目ID隔离，这仍不能证明真实阅卷准确率。

诊断还发现符号数量、LRU淘汰方向、中断返回点等高置信错误。新增少量明确谓词的冲突过滤后，C#运行时在这68条诊断断言上错误给分为0、分类正确53条、正确给分21条。过滤规则是在观察诊断错误后补充的，因此不能再将该集合称为独立留出测试。FP16与FP32的断言判定一致。

另对124道新增题用参考文本运行完整评分链路，检查分页、长答案检索与全部评分点是否接通；这属于接入检查，不是准确率评估。本轮该检查最低16分、平均76.45分，漏给分仍明显。具体记录见本机`reports/wakuu-canonical-integration.json`，不能把“已接通评分”理解为“已可靠判分”。

当前没有独立人工标注的真实答卷测试集；不同正确解法可能漏给分，错误论证也可能被模型高置信接受。公开版本明确标注“实验核分”，不能宣称全部大题已达到可靠教师阅卷水平。

## 本地重现

Python环境需要PyTorch 2.5.1（本次CUDA12.1）、Transformers 4.46.2、NumPy，以及`.tools/ai-python`中的ONNX1.17.0和ONNX Runtime1.23.2。需要合法游戏安装、分别导入的本地题库、模型开发依赖和固定底模。首次准备需联网下载，游戏运行无需网络。

```powershell
./PrepareWakuu.ps1
./TrainWakuu.ps1
dotnet run --project tests/CoreTests.csproj
./Build.ps1 -SkipAssets -Install
./SmokeTest.ps1
```

构建、训练和验证脚本均公开。模型和源题库授权与项目MIT源码分开；来源与致谢见根目录`THIRD_PARTY_NOTICES.md`。

原35道、后续80道的旧事件评分细则保持不变，按已登记题库散列迁移。旧局保留其原大题题序；新局可以抽到全部204道题。改变模型不会追扣或补发已经结算的历史奖励。
