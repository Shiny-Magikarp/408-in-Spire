# 创意工坊上架评估

检查日期：2026-10-27，当前开发版0.8.3。判断：玩法和界面已具备Windows测试版的基础；完整题库包的公开分发依据尚未确认，发布工程与独立玩家测试也没有完成，暂不建议把现有完整本地包直接公开上架。

## 已有基础

- 四科/章节/来源/错题筛选、主动激活学识徽记、答对10金币和本次伤害/格挡翻倍、30/60/90答题金币上限、卡牌和遗物自身产金。
- 1,676道可玩选择题，668道隔离；195道可玩大题，9道含绘图要求的混合题已移除。
- dev3完全离线，模型约205MB，完整Mod约255MB；阈值保持0.85/0.1。0.8.2的新100条项目编写表述中给分决定正确92条，但这不是全部大题的真实人工阅卷一致率。
- 编辑器场景与导出绑定保留，中文试玩说明、MIT源码、第三方许可与公开GitHub仓库已有。
- 核心检查覆盖奖励、防重复、旧局迁移；游戏集成测试使用隔离存档。检查通过不等于已完成普通玩家的完整三幕游玩和干净安装验证。

以上“发布前验证”是本项目建议的发布门槛，不是对Steam审核条款的转述。跨平台支持、联机、更多题量和继续扩大模型可放在后续版本，不必阻挡明确标注范围的Windows测试版。

## 建议随后改进

- 让玩家方便地复制题目ID、题干/解析版本和模型版本，并通过GitHub Issue反馈错题或误判。当前选择题弹窗没有专用纠错入口。
- 补充低分辨率/窗口缩放、不同长度答案、首次加载耗时和较弱CPU的实际体验测试。
- 用独立标注样例评估整题练习分与部分正确答案。算法题当前比对参考评分点，不执行任意C/C++代码；页面应继续保留实验性说明。
